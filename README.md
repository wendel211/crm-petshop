# crm-petshop

CRM para pet shops, clinicas veterinarias e banho/tosa, com foco inicial em empresas de Feira de Santana.

Este repositorio sera desenvolvido de forma incremental com apoio de agentes do Codex, usando ciclos diarios de planejamento, implementacao, validacao e abertura de PR.

## Stack inicial

- Next.js com App Router
- TypeScript
- Tailwind CSS
- ESLint

## Como rodar

```bash
npm install
npm run dev
```

Abra `http://localhost:3000` para acessar o painel inicial.
